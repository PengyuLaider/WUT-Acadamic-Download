# 界面与验证记录

更新日期：2026-10-31。

用户选择“校园门户风格：白底＋深蓝，正式清晰”。保留原来的本地 Python 服务，拆分 HTML/CSS/JS，不增加前端构建依赖。采用本机字体，不加载外部字体或第三方资源。标识与校园建筑线稿为本项目自行绘制，不使用学校官方徽标；页面明确标注独立工具。

## 交互与可视化

账号配置、学校认证、全文核验分别显示，保存配置不会把后两步误标为完成。初次配置、已保存、缺字段、服务异常、保存中、保存成功分别提供反馈。已保存的账号密码不回显；留空保留原值，变更账号时要求对应新密码。密码切换只显示本次输入值，保存后清空输入并恢复隐藏。

保存请求检查页面令牌与请求来源，静态文件按清单提供；不开放任意本地文件读取。无账号的静态演示可直接由 `docs/demo/index.html` 打开，所有输入仅在页面模拟。

## 实际核验

- 本地 HTTP 集成测试 16 项：模拟账号、临时文件，覆盖保存、保留已有值、损坏文件保护、跨站请求拒绝、令牌、静态路径和演示模式。
- 浏览器使用受支持的 CUA 工具核验，未用自建 CDP 绕过宿主限制。
- 1280 × 1000、768 × 1024、390 × 844 三种视口：均未发现横向溢出；截图在 `docs/images/`。
- 实际点击验证：空表单错误定位、密码显示/隐藏、演示保存、保存后清空输入、下一步状态和步骤展开。
- 页面错误日志为空。未在这轮测试真实学校登录、真实密码或真实论文下载。

桌面与手机完整截图经过视觉回看；字体、布局、边界、状态和说明可读。尚未完成屏幕阅读器等全面无障碍审计，不能宣称完整 WCAG 合规。

## 启动方式变更

开发时生成的后台启动脚本 `start_ui.ps1` 被安全软件删除。本版未恢复该文件，也未更改安全软件设置。配置界面改为 Python 前台终端运行，不隐藏窗口、不自动修改 ACL、不要求执行策略绕过；关闭终端或 Ctrl+C 停止。检测原因未完成安全软件侧取证，未定性为误报。

浏览器下载脚本的自动 PowerShell 置顶调用已去除，保留浏览器自身的置前请求。Cookie 下载回退不再向重定向地址沿用原 Cookie/Authorization，并补大小上限；验证等待更新当前页面状态再尝试填表。这些变更做离线检查，仍需后续真实站点回归。
