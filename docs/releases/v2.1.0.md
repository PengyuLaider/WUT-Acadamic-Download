# v2.1.0 · 2026-11-02

本版整合本机最新改进与使用报告反馈，保留 v1.0.0 / v2.0.0 快照。功能没有“所有站点保证成功”的承诺，学校认证、验证码、逐篇订阅与稿件版本仍分别判断。

## 功能

- Windows 默认 DPAPI 加密配置，Node 通过本地 Python DPAPI 桥消费密文。使用同一 Windows 用户；密文不作为可分享配置。加密失败停止保存，不自动回退明文。明确选择 --no-dpapi 才使用明文。
- batch 支持 --workers、--state、--resume 与逐域限速；续跑重新检查文件、哈希与篇目身份，待核验、缺失或损坏文件不直接跳过。
- 中文 DOI 增加解析与官网链接发现路径；结果受 DOI 登记与期刊站点可用性影响，不能把所有未解析条目当作无全文。
- import-file 提供单行 JSON、自定义文件名、作者/年份/期刊和版本/来源类型。许可证信息未知时保持未知，不从期刊名或下载站点推断许可。
- 下载候选、按钮、请求回放与内嵌路径补充图片/参考文献过滤。成功要求结构与篇目核验通过，单页预览须人工确认；可疑文件隔离保留。隔离因权限失败时保留文件并报告，不提权删文件。
- 代理冲突保留既有会话，不自动关闭浏览器。浏览器启动权限错误提供本人本机或宿主支持工具的接续建议，不绕过宿主限制。
- 校内私网、教育网 ASN 仅为线索，不足以单独证明学校位置或目标论文授权。保留诊断失败与证据不足的区别。
- 恢复并扩充中文/English 界面提示，公开软件使用 MIT 许可证；第三方论文和数据不随软件授权。

## 验证与边界

发布回归：80 项 Python、37 项 Node 测试及 177 项 PowerShell 离线断言，另有 WebVPN URL 样本自检。DPAPI 用假凭据验证当前 Windows 用户的加解密与页面不回显；不会使用用户真实配置。

另一位智能体的本机报告记录了 4 篇指定论文通过题名/DOI 核验；该实测发生在本次整合前，属于来源报告，不能代表本版每条浏览器分支已重新现场验收。学校账号认证、CARSI、中文 DOI 全站点、并发性能及出版社页面变化仍需用户环境复验。完整报告、本机地址和下载清单未上传。

## 隐私与兼容

- 干净发布附件排除真实明文/密文凭据、论文、清单、浏览器会话、缓存、现场报告与本机路径；仅包含空白示例与源码测试。
- 单独安装 skill 时显式传 --credentials 或 CAMPUS_CREDENTIALS；不扫描其他技能或无关工作目录寻找账号。
- 退出码：0 完成、1 错误、2 本人处理或来源不可用、3 部分完成/待核验；JSON status 比退出码更具体。与 2.0 的部分码不同，脚本调用方需检查。
- 不能把 Cookie 保存描述为永久免验证，不清理用户 Cookie、不自动重试错误密码，不绕过验证码或付费墙。
- 本机旧包、私密配置、已下载论文与历史备份未移动或删除。整理后的新版本目录可独立使用；凭据迁移需本人在本机完成。

## English

Version 2.1 integrates DPAPI defaults, concurrent and resumable batches, Chinese DOI discovery, provenance fields, conservative PDF identity checks and bilingual UI. Encryption failures stop saving; questionable downloads are retained for review; proxy conflicts preserve the browser session. Resume revalidates files and identity. Field reports are explicitly distinguished from this release's offline evidence. Private credentials, papers, profiles and local reports are excluded from release assets.
