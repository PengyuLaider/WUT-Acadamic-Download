## 交给能接入校内网的智能体

先读取上述边界，再在用户授权的宿主浏览器运行；宿主禁止直接 CDP 时，不以 browser_dl 绕过限制。保留浏览器、配置和已下载文件，不清空 profile，不关闭安全软件。

1. **获取样本**：原始清单；报告中的 B04/E03 原文件；对应完整 DOI、题名与原命令；正确与错误文章各一个脱敏样例。不要索取密码、Cookie、签名 URL 或原始含凭据日志。
2. **优先验收 P0**：目标文章与参考文献拥有不同 PII；页面包含配图链接；会话过期/门户主页；单页预览；正确全文。确认跨导航、按钮、请求回放、内嵌和下载事件路径均不把错篇列为 downloaded。保存等待、登录墙、隔离与 JSON 状态也须核对。
3. **复验现场认证**：`submit_button_not_found` 的真实 DOM；学校允许的 CARSI 入口及返回文章路径。验证码由本人处理，成功不能只看页面跳转或机构名称。
4. **出版社入口**：报告称改写 WebVPN 挑战循环、校园 IP 下正常浏览器导航可下载，这是待复验个案。仅沿用当前获授权页面中属于目标 PII 的官方下载入口；签名链接短期有效且不能公开记录。不要扩大为绕过验证或付费墙的方法。
5. **中文论文**：使用完整 DOI 确认 DOI 解析及期刊官网，人工确认文章对应关系后建立固定脱敏测试样例。一个期刊成功不能推断全部同前缀成功。
6. **回报证据**：每篇目标 DOI、稿件版本、脱敏文章落地页、文件 SHA-256、页数、身份核验、状态、待人工原因，以及操作对应提交号。对报告中的 45/50 结果单独复查，不把它当成本轮成功率。
