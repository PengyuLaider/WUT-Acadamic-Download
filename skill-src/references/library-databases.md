# 数据库页面处理

这些是站点差异与原包功能范围，不是武汉理工大学当前订阅清单。本轮未重新联网验证任何站点的下载流程。使用时从学校当前图书馆导航或用户提供的文章页进入。

| 页面 | 操作要点 |
|---|---|
| 知网 | 搜索结果可能有动态参数；先核对题名和作者，再进单篇详情。PDF 与 CAJ 不同，CAJ 不得改扩展名冒充 PDF。滑块由用户完成。 |
| 万方 | 搜索页和 `d.wanfangdata.com.cn` 详情页可能不同域。无可见文章链接时返回未解析，不能猜测或自动选第一条。 |
| 维普 | 详情与检索入口不同；全文可能在其他阅读器或资源平台，需逐次确认目标。 |
| ScienceDirect / Cell / Elsevier | 摘要页不代表全文权限；PDF 可能进入阅读器或签名 CDN 地址并再次要求验证，用户在对应标签处理。 |
| Springer / Nature / Wiley / IEEE / ACM | 以当前文章页实际全文权利为准；机构标志不等于该篇可下载。附件、勘误与正文需分清。 |
| Web of Science / Scopus / PubMed | 主要提供检索、摘要和元数据，跳转出版社后再判断全文权限。 |

## 浏览器 CLI 的边界

`--site cnki|wanfang|vip --search "关键词"` 默认只输出 `selection_required` 和候选；不自动下载。优先使用确认后的文章 URL。若用 `--select N`，同时传原列表题名 `--title` 防止排序变化选错；不匹配会停止。

脚本保留同源页面 fetch、点击下载、网络事件候选、内嵌阅读器等原有路径。浏览器文件捕获只接收本次文章 frame 的已完成下载事件，不把输出目录中其他程序新建的 PDF 当作本次结果。新窗口/跨进程阅读器可能无法归属；这种情况让用户保存后 `import-file`。

`--dump` 仅给精简标题、链接和验证标志，不输出整页 HTML、表单值或 Cookie。页面字段、下载事件、验证码判断和 DOM 定位仍须在用户环境验收；跨站下载可能较原包减少一条自动路径，需正常浏览器保存兜底。

不能根据连接超时判断“未订阅”，也不能把一个站点上成功下载推广为所有站点都支持。无需安装新的下载插件，除非用户主动选择。
